# Codex Element Explanations

This document briefly explains key components used in the repository. It can be
referenced by other agents or systems when extending the Divine-Ascension
System.

- **OntologicalState**: enumeration of the three philosophical phases an agent
  can inhabit: `Ego`, `Jaz`, and `Enotnost`.
- **Agent**: main entity in the system that moves between ontological states
  based on internal `tension` and `emotion` values.
- **philosophical_dialogue**: helper that orchestrates a short conversation
  between two agents while demonstrating state transitions.

These explanations are kept short so they can easily be displayed in Codex or
other interactive systems.
