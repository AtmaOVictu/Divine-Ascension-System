# Divine-Ascension-System

This project contains a minimal agent-based framework for simulating
philosophical dialogues. Agents move between ontological states
(`Ego`, `Jaz`, and `Enotnost`) based on their current **tension** and
**emotional** levels. The `dialogue` module lets two agents influence
each other and transition through these states while expressing answers
that reflect their perspective on truth.

## Running Tests

The system uses the standard `unittest` module. Execute all tests with:

```bash
python -m unittest discover tests
```
