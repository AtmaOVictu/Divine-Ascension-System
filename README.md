# Divine-Ascension-System

This project demonstrates a simple ontological agent system where agents
transition between three philosophical states: **Ego**, **Jaz**, and
**Enotnost**. State changes occur when the agent's tension exceeds `0.7` or an
emotion exceeds `0.5`.

## Running Tests

The repository includes unit tests located in the `tests` directory. Execute
the tests with:

```bash
pytest -q
```

The tests verify correct state transitions, emotional influence on responses and
the sample philosophical dialogue.
