# Divine-Ascension-System
UX HUB FOR INTERACTIVE COMMAND/

This project models philosophical agents that transition between the ontological
states **Ego**, **Jaz** and **Enotnost**. Agents maintain emotional intensity and
tension levels. When these values exceed configured thresholds, an agent moves
to the next state. Dialogues showcase how emotions influence the agents'
responses about absolute, relative and unified truths.
