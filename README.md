# Divine-Ascension-System
UX HUB FOR INTERACTIVE COMMAND/

This repository contains a minimal ontological agent framework. Agents move
through three philosophical states:

- **Ego** – truth is absolute.
- **Jaz** – truth is relative.
- **Enotnost** – all truths are unified.

Agents react to emotions and tension. When `tension > 0.7` or `emotion > 0.5`
they transition to the next state. The package includes a small dialogue engine
and unit tests to demonstrate these transitions.
