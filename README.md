# Divine-Ascension-System

This repository contains a simple ontological agent framework. Agents
transition between three philosophical states (**Ego**, **Jaz**, and
**Enotnost**) based on their emotional intensity and tension levels.

Features include:

* Dynamic state transitions when `tension > 0.7` or `emotion > 0.5`.
* Philosophical dialogue simulation between agents.
* Introspection utilities for logging internal states.
* Unit tests demonstrating transitions and introspection behavior.
