# Divine-Ascension-System

This project provides simple agent classes for exploring philosophical
transitions and emotional reflection.  Agents move through three ontological
states (**Ego**, **Jaz**, **Enotnost**) according to their tension and emotion.

Additional utilities demonstrate `idself` and `iffself` concepts for managing
emotional tasks and reflective dialogue.

## Running Tests

Install `pytest` and run:

```bash
pytest -q
```

The tests cover state transitions, responses, dialogues, and emotional
reflection utilities.
