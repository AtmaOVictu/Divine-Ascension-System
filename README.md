# Divine-Ascension-System

Interactive hub for simulating ontological agents that debate absolute,
relative and unified truths. The system models three philosophical states:

* **Ego** – truth is absolute and independent of others.
* **Jaz** – truth is relative and shaped by relationships.
* **Enotnost** – all truths are one and interconnected.

Agents transition between these states when their tension exceeds `0.7` or
their emotion exceeds `0.5`. Dialogue functions showcase how emotional
intensity influences the conversation and state changes.

## Running the tests

Install `pytest` and run:

```bash
PYTHONPATH=. pytest -q
```

This executes unit tests that verify state transitions, emotional responses and
dialogue output.
