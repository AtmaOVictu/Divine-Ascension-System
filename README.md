# Divine-Ascension-System

This project provides a small framework for simulating ontological agents that
transition between philosophical states based on emotion and tension. The
package includes:

* `divine_agents.agent` – an `Agent` class capable of transitioning between
  **Ego**, **Jaz**, and **Enotnost** states.
* `divine_agents.dialogue` – helpers for running short philosophical debates
  between agents.
* Unit tests under `tests/` ensuring transitions and dialogue behaviours work as
  expected.

Run tests with `pytest` to verify everything functions correctly.
