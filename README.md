# Divine-Ascension-System

Simple framework for experimenting with ontological agents and their
philosophical dialogues. Agents can reside in three states:

- **Ego** – truth is viewed as absolute.
- **Jaz** – truth becomes relative and shaped by relationships.
- **Enotnost** – all truths are unified.

State transitions are triggered when an agent's tension exceeds `0.7` or
emotion intensity exceeds `0.5`. Emotions influence dialogue output and can be
updated dynamically.

Unit tests are provided in the `tests` folder to verify transitions and sample
dialogue generation.
