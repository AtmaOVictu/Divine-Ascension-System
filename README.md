# Divine-Ascension-System

This project implements a minimal simulation of ontological agents.  Agents
transition between the states **Ego**, **Jaz** and **Enotnost** based on their
emotional intensity and tension.  A small dialogue utility showcases how these
agents debate philosophical questions.

## Running the tests

Tests are written with ``unittest`` and can be executed with ``pytest``:

```bash
PYTHONPATH=. pytest -q
```
