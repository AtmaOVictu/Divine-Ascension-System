# Divine-Ascension-System

This project demonstrates a simple multi-agent framework where agents hold
philosophical perspectives and interact with one another. Each agent has
emotional state and tension levels that influence transitions between three
ontological states: **Ego**, **Jaz**, and **Enotnost**.

## Usage

Run the simulation to see a sample conversation:

```bash
python -m src.simulation
```

This will print a short dialogue in which three agents debate the nature of
truth and influence each other's emotional state.

## Running Tests

Install `pytest` and execute the tests from the repository root:

```bash
pytest
```

The included test verifies that a conversation includes responses representing
all three philosophical perspectives.
