# Divine-Ascension-System

A small framework demonstrating ontological agents that transition between
philosophical states. Agents move from **Ego** to **Jaz** to **Enotnost** when
tension or emotion thresholds are exceeded. The package also provides tools for
simulating dialogues and running transition cycles for multiple agents.

## Components

- `Agent` manages state, tension, and emotion.
- `philosophical_dialogue` simulates a short exchange between two agents.
- `OntologicalSystem` runs repeated transition cycles and records the results.

## Running Tests

Use `python -m pytest -q` to execute the unit tests.
