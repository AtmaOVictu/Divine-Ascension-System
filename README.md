# Divine-Ascension-System
UX HUB FOR INTERACTIVE COMMAND/

## Overview

This project contains a simple simulation of ontological agents that can
transition between the states **Ego**, **Jaz**, and **Enotnost**. The agents
track an internal RES phase (1&ndash;100) and evolve through phases via
evolution, permutation, and degradation operations.

Unit tests are provided under `tests/` and can be executed with:

```bash
python -m pytest -q
```
