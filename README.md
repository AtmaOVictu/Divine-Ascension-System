# Divine-Ascension-System

Divine-Ascension-System simulates interactions between ontological agents. Each agent
shifts between philosophical states based on emotion and tension, enabling rich
philosophical debates.

## Ontological States
- **Ego (\u2298)**: Truth is *absolute* and independent of others.
- **Jaz (\u222B(dru/x))**: Truth is *relative*, shaped by relationships and
  experiences.
- **Enotnost (RES001)**: All truths are one; separation is an illusion.

## Installation
The project does not yet provide a Python package. Once packaging is added you
can install it in editable mode:

```bash
pip install -e .
```

## Running Tests
Execute the unit tests with:

```bash
python -m unittest
```
