# Divine-Ascension-System

This repository contains a small ontological agent framework. Agents move
between the philosophical states **Ego**, **Jaz** and **Enotnost** based on
their emotional intensity and tension levels. A simple dialogue module shows
how agents debate absolute, relative and unified truths.

## Running the tests

Use `pytest` to execute the test-suite:

```bash
PYTHONPATH=. pytest -q
```
