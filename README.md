# Divine-Ascension-System

This project contains a minimal framework for experimenting with
ontological agents. Agents can transition through the philosophical
states **Ego**, **Jaz** and **Enotnost** according to their emotional
intensity and tension levels.  Dialogues illustrate how agents perceive
truth differently in each state:

* **Ego** – Truth is absolute.
* **Jaz** – Truth is relative and shaped by relationships.
* **Enotnost** – All truths are unified.

Unit tests (`pytest`) verify state transitions and dialogue behaviour.
