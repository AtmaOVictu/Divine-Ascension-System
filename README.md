# Divine-Ascension-System

This project explores philosophical transitions between ontological states. The
agents evolve from **Ego** to **Jaz** and finally to **Enotnost** based on their
internal tension and emotion.

## Running Tests

Execute the unit tests with:

```bash
python -m pytest -q
```

## Interactive UI

A simple Tkinter interface visualizes a single agent and allows you to increase
its tension or emotion. Run the interface with:

```bash
python -m divine_agents.gui
```

Color changes indicate the agent's current state (red, yellow, or green) and the
label displays a philosophical response depending on the state.
