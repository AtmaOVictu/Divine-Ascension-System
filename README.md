# Divine-Ascension-System

This project models philosophical agents that transition between ontological
states. The available states are:

1. **Ego** – truth is absolute and independent of others.
2. **Jaz** – truth is relative and shaped by relationships.
3. **Enotnost** – all truths are interconnected.
4. **Razsvetljenje** – truth transcends concepts in pure unity.

Agents shift to the next state when their tension exceeds `0.7` or their
emotion exceeds `0.5`. Dialogues illustrate how agents in different states
respond to questions about truth.
