# Divine-Ascension-System

This project demonstrates a minimal agent-based framework where agents
transition between the ontological states **Ego**, **Jaz** and **Enotnost**.
Transitions occur when either the agent's tension is above `0.7` or the
emotional intensity rises above `0.5`.  Agents reply to philosophical questions
according to their current state and emotional flavour.

## Running tests

To execute the unit tests run:

```bash
python -m pytest -q
```
