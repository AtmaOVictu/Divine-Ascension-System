## Dynamic Agents
This system includes `DynamicAgent` instances that may be **dynamic** or **antidynamic**. Dynamic agents can change state when their emotion or tension rises above thresholds (0.5 and 0.7). Antidynamic agents always remain in the `Ego` state. The `dinamicka_inicializacija` function connects active agents and triggers reorganization for dynamic ones.
