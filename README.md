# Divine-Ascension-System

This repository contains a minimal demonstration of an ontological multi-agent
system. Agents move between philosophical states—**Ego**, **Jaz** and
**Enotnost**—according to their emotion and tension levels. A simple dialogue
module showcases how agents debate absolute, relative and unified truths while
their emotions trigger state transitions.

Unit tests ensure that transitions occur when the required thresholds are met
and that dialogues reflect the agents' evolving states.
