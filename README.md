# Divine-Ascension-System

This repository simulates agents transitioning between ontological states (Ego, Jaz, Enotnost) based on emotional tension and philosophical principles. Agents engage in dialogues about truth, and their emotional states influence both their responses and state transitions.

## Installation
Install dependencies with:
```bash
pip install -r requirements.txt
```

## Usage
Run the example dialogue:
```bash
python -m divine_agents.dialogue_example
```

## Running Tests
Execute the unit tests with:
```bash
python -m unittest discover -s tests -p 'test*.py'
```
