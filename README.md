# Divine-Ascension-System

This repository contains a small simulation of ontological agents that
transition between states **Ego**, **Jaz** and **Enotnost**.  Transitions are
driven by the agents' emotional intensity and tension.  Dialogue between agents
reflects their current state and emotional tone.

## Running Tests

All behaviour is covered by a small test-suite.  Execute the tests using

```bash
python -m pytest -q
```
