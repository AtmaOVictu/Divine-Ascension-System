# Divine-Ascension-System

This repository provides a small framework for simulating **ontological agents**
that transition between philosophical states based on emotion and tension. Each
agent can exist in one of three phases:

- **Ego** – truth is absolute and independent of others.
- **Jaz** – truth is relative and shaped by relationships.
- **Enotnost** – all truths are unified and interconnected.

Agents update their emotional intensity and tension, influencing state
transitions once thresholds are reached. The package also includes utilities for
philosophical dialogues where agents debate the nature of truth.

Run the unit tests with `pytest` to verify that transitions and dialogues work
as expected.
