# Divine-Ascension-System

This project explores philosophical dialogues between agents that
transition through the ontological states **Ego**, **Jaz**, and
**Enotnost**. Agents change states when their emotional intensity or
tension crosses defined thresholds.

## Installation

Install the package in editable mode and run the tests:

```bash
pip install -e .
pytest -q
```

## Usage

The package provides an `Agent` class and a `philosophical_dialogue`
function for simulating conversations. See `tests/test_agents.py` for
examples of typical interactions.
