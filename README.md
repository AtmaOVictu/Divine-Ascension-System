# Divine-Ascension-System

This project provides a minimal framework for exploring ontological state
transitions between **Ego**, **Jaz** and **Enotnost**. Agents respond to
philosophical questions and adjust their emotional state and tension during
dialogues. When emotion exceeds ``0.5`` or tension exceeds ``0.7`` an agent
changes state accordingly.

## Running tests

Install the requirements (if any) and run the unit tests with:

```bash
python -m unittest
```
