## State Interpretations of Questions

Different ontological phases interpret the same question in unique ways:

- **Ego** believes truth is absolute and independent of anyone else.
- **Jaz** sees truth as relative and shaped by relationships.
- **Enotnost** views all truths as unified and interconnected.

The method `Agent.respond(question)` returns a sentence that includes the
original `question` string so that the reasoning of the agent is explicit.
