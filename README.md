# Divine-Ascension-System

This project contains a simple agent-based framework exploring ontological
transitions between the philosophical states **Ego**, **Jaz** and **Enotnost**.
Agents react to emotional input which can increase their tension and trigger
state changes. A small dialogue module simulates interactions between two
agents discussing various views on truth.

## Running Tests

The package uses the standard ``unittest`` library. From the repository root
run:

```bash
python -m unittest discover -s tests
```
