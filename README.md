# Divine-Ascension-System

This package provides a simple framework for simulating ontological agents. Agents
transition between the philosophical states **Ego**, **Jaz**, and **Enotnost**
based on their emotional intensity and tension levels.

Key modules include:
- `agent` – core agent logic with state transitions.
- `emotion` – management of emotional states.
- `dialogue` – utilities for creating philosophical dialogues.
- `ethics` – minimal ethical judgement support.
- `real_data` – placeholder for connecting real sensor data.
- `visualization` – ASCII based visualisation of transitions.
- `reinforcement` – stub for reinforcement learning integration.

Unit tests are located in `tests/`.
