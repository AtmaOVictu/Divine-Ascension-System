# Divine-Ascension-System

This repository contains a small agent-based framework used to explore
ontological state transitions and philosophical dialogues. Agents move through
the states **Ego**, **Jaz**, and **Enotnost** based on their emotional intensity
and tension levels.

## Components

- **divine_agents.agent** – core `Agent` class implementing state transitions.
- **divine_agents.dialogue** – helper for simulating short conversations
  between agents.
- **divine_agents.symbols** – collection of Luka Pintarič symbols with
  descriptions.

Unit tests live under the `tests` directory and can be executed with `pytest`.
