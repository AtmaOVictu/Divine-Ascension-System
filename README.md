## Emotional Influence on Philosophical Responses

`Agent.respond()` accepts an optional `emotion` parameter which alters the
statement returned for each ontological state. The mapping below shows how
each emotion modifies the reply.

| State     | Fear prefix                                | Joy prefix                              | Anger prefix                           |
|-----------|--------------------------------------------|-----------------------------------------|---------------------------------------|
| **Ego**   | "V strahu zagovarjam, da"                  | "Z veseljem trdim, da"                  | "V jezi vztrajam, da"                 |
| **Jaz**   | "S strahom razumem, da"                   | "Z radostjo vidim, da"                  | "V jezi spoznavam, da"                |
| **Enotnost** | "Čeprav me je strah, verjamem, da"      | "Z veseljem razkrivam, da"              | "Kljub jezi verjamem, da"             |

These prefixes are prepended to the base statement of the respective state:

- **Ego** – truth is absolute and independent of others.
- **Jaz** – truth is relative and shaped through relationships.
- **Enotnost** – all truths are one and interconnected.
