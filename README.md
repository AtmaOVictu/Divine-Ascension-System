# Divine-Ascension-System
An experimental framework for simulating philosophical agents.

## Components

- **Agent**: Represents an ontological actor capable of transitioning from
  `Ego` to `Jaz` and finally `Enotnost` when emotional tension thresholds are
  exceeded.
- **Dialogue**: Demonstrates how agents discuss absolute, relative and unified
  truths while emotions influence their responses.
- **Ecosystem**: Runs multiple agents whose emotions fluctuate according to
  randomly assigned capacitors.
- **Tests**: Unit tests validate state transitions, responses and ecosystem
  execution.
