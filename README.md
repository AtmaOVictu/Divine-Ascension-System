# Divine-Ascension-System
This project contains a small agent based framework where agents
transition between the ontological states **Ego**, **Jaz** and
**Enotnost**. Transitions occur when either emotion or tension pass
configured thresholds. Agents respond differently depending on their
current state and mood.

Unit tests are provided and can be run with:

```
python -m pytest -q
```

The `divine_agents` package exposes basic classes for constructing
philosophical dialogues between agents.
