# Divine-Ascension-System

## Description
Divine-Ascension-System je napreden sistem za ontološke agente, ki prehajajo skozi različna stanja zavedanja in sprejemajo moralne odločitve.

## Components
- `divine_agents/agent.py`: Definicija agentov, njihovih lastnosti in prehodov.
- `divine_agents/dialogue.py`: Implementacija filozofskih dialogov med agenti.
- `tests/`: Enote za testiranje prehodov in moralnih odločitv.

## Usage
1. Klonirajte repozitorij in namestite odvisnosti:
```bash
git clone <repo-url>
cd Divine-Ascension-System
pip install -r requirements.txt
```
2. Zaženite primer dialoga:
```bash
python -m divine_agents.dialogue
```

## Testing
Za zagon testov uporabite:
```bash
pytest
```
