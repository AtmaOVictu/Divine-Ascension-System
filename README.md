# Divine-Ascension-System

This project implements a minimal agent-based framework exploring three
ontological states: **Ego**, **Jaz** and **Enotnost**. Agents transition between
these states when their internal tension or emotion rises above predefined
thresholds.  Dialogues showcase how different states interpret truth.

## Running Tests

Execute the unit tests with:

```bash
python -m pytest -q
```
