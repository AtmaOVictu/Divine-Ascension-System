# Divine-Ascension-System

This repository hosts a simple ontological agent framework. Agents transition
between philosophical states (**Ego**, **Jaz**, **Enotnost**) based on emotion
and tension levels. The package lives in `src/divine_agents` and unit tests are
located under `tests`.

## Running tests

```
pytest -q
```

## Continuous Integration / Deployment

GitHub Actions workflows under `.github/workflows` automatically test every
change and demonstrate how code could be deployed.
