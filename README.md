# Divine-Ascension-System
This repository contains a minimal simulation of philosophical agents.

Agents transition between ontological states (**Ego**, **Jaz**, **Enotnost**) based
on their tension and emotions. Dialogues are managed through a `SymbolicBox`
object that enforces a simple ontological flow (∴, ∆, ⊘).

Run tests with:

```bash
python -m unittest
```
