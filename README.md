# Divine-Ascension-System

This project provides a minimal framework for simulating philosophical agents.
Agents transition between three ontological states:

* **Ego** – truth is absolute and independent.
* **Jaz** – truth is relative and shaped by relationships.
* **Enotnost** – all truths are unified and interconnected.

Agents maintain an emotional state that influences their tension and state
transitions. A short dialogue demonstrates how emotions change during
conversation.

## Running the tests

The repository contains unit tests verifying state transitions and dialogue
generation. Execute them with:

```bash
pytest -q
```
