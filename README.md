# Divine-Ascension-System
UX HUB FOR INTERACTIVE COMMAND/

## Spiritual Rebirth Module
This project contains a modular agent system where agents transition between
philosophical states **Ego**, **Jaz**, and **Enotnost** based on emotional
intensity and tension. The new module `divine_agents/spiritual_rebirth.py`
implements these behaviors and provides a function to simulate a
philosophical debate between agents.

### Running Tests
All tests can be executed with:

```bash
python -m unittest discover -s tests
```
