# Divine-Ascension-System

This project provides a small ontological simulation where agents evolve
through the states **Ego**, **Jaz** and **Enotnost**.  Each agent carries an
emotional intensity and a descriptive emotion name which influence their
tension.  When tension or emotion exceed configured thresholds, the agent
transitions to the next ontological level.

The package exposes utilities for running simple philosophical dialogues
and includes unit tests that verify transitions and responses.
