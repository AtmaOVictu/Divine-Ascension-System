# Divine-Ascension-System
UX HUB FOR INTERACTIVE COMMAND/

## Operacijska miza

Za zagon preprostega grafičnega vmesnika lahko uporabite Streamlit. V
mapi `divine_agents` se nahaja skripta `desk.py`, ki omogoča vpogled v
stanje agentov, nastavljanje čustev in sprožanje filozofskih dialogov.

```bash
streamlit run divine_agents/desk.py
```

S tem se prikaže interaktivna "miza" za nadzor agentov.
