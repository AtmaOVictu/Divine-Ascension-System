# Divine-Ascension-System

This project demonstrates a small ontological agent system. Agents transition
between **Ego**, **Jaz** and **Enotnost** states according to their emotional
intensity and tension. The system also includes a short philosophical dialogue
showcasing how emotions influence the discussion about absolute, relative and
unified truths.

## Running tests

Tests are written with `unittest` and can be executed using `pytest`. The
repository contains a `pytest.ini` file which ensures the project root is on
`sys.path`, so running the tests from the project directory is enough:

```bash
pytest
```
