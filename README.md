# Divine-Ascension-System
UX HUB FOR INTERACTIVE COMMAND/

This project simulates ontological agents that move between three states:
**Ego**, **Jaz** and **Enotnost**. Agents change state when their tension
exceeds `0.7` or their emotion exceeds `0.5`. Dialogue utilities allow agents
to debate philosophical truths based on their current state.

Additional modules introduce container based processing (`AwarenessContainer`,
`OppositionContainer`, `TransitionContainer`) demonstrating forced modular
usage. Tests verify state transitions, dialogue outcomes and container
functionality.
