# Divine-Ascension-System

This project provides a simple framework for simulating philosophical agents and their dialogues. The package exposes the `divine_agents` module with components for creating agents and running dialogues.

## Installation

Install in editable mode so the tests and examples can import `divine_agents` directly:

```bash
pip install --no-use-pep517 --no-build-isolation -e .
```

After installation you can run the unit tests with `pytest`.
