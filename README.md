# Divine-Ascension-System

This project provides a minimal agent-based framework that explores
philosophical state transitions. Agents move from **Ego** to **Jaz** and
ultimately **Enotnost** based on their emotional intensity and tension.

## Usage

The package can be used directly after cloning the repository:

```bash
python -m divine_agents.dialogue
```

## Running Tests

Install `pytest` and execute the test suite from the repository root:

```bash
pip install pytest
pytest -q
```

All tests should pass and verify state transitions and dialogue behaviour.
