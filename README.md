# Divine-Ascension-System

This project simulates a dynamic agent-based system where agents transition between philosophical states based on their emotions and tension levels. Agents in the states **Ego**, **Jaz**, and **Enotnost** express different views of truth and interact through philosophical dialogues. Unit tests ensure that state transitions and responses behave as expected.

## Setup

Create and activate a virtual environment:

```bash
python3 -m venv venv
source venv/bin/activate
```

The project currently relies only on the Python standard library. If dependencies are added later, install them with:

```bash
pip install -r requirements.txt
```

## Running Tests

Execute the unit tests with:

```bash
python -m unittest
```

This command discovers and runs all tests in the `tests` directory.
