# Divine-Ascension-System

This project simulates interactions between ontological agents that can transition between three philosophical states.

## Ontological States

- **Ego (⊘)** – Truth is **absolute** and independent of others.
- **Jaz (∫(dru/x))** – Truth is **relative**, shaped by relationships and interactions.
- **Enotnost (RES001)** – All truths are **unified** and interconnected.

## Emotion and Tension Thresholds

Agents transition to the next state when either:

- **Tension** exceeds **0.7**, or
- **Emotion** exceeds **0.5**.

For example, an agent in `Ego` moves to `Jaz` when these thresholds are met. A `Jaz` agent transitions to `Enotnost` under the same conditions.

## Running Tests

The repository contains unit tests in the `tests/` directory. Run them with:

```bash
python -m unittest discover tests
```

## Dependencies

- Python 3.11 or newer is recommended.
