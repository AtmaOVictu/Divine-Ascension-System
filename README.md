# Divine-Ascension-System

This project contains simple ontological agents used for simulating philosophical dialogues.

## Modules

- **Agent**: Handles ontological state transitions between `Ego`, `Jaz`, and `Enotnost` based on tension and emotion.
- **WordAgent**: Models a word as a dynamic agent that can activate and resonate through different energy states.
- **Library**: Utility for building collections of word agents.

Unit tests ensure correct behaviour of transitions, responses, and the word library.
