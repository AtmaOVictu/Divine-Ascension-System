# Divine-Ascension-System

This project demonstrates a simple ontological agent framework. Agents transition between philosophical states **Ego**, **Jaz**, and **Enotnost** according to their emotional intensity and tension. The provided modules allow you to simulate dialogues where agents discuss truths and evolve through these states.

## Running the sample dialogue

A small script `sample_dialogue.py` is included. It runs a conversation between two agents and prints each line of the dialogue. Execute it with:

```bash
python sample_dialogue.py
```

## Running the tests

Automated tests reside in the `tests/` directory. Run them using `pytest`:

```bash
python -m pytest
```
