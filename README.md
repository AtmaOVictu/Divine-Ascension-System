# Divine-Ascension-System
UX HUB FOR INTERACTIVE COMMAND/

## Agent Attributes

- **name**: Unique identifier used to address the agent.
- **state**: The ontological state of the agent. Valid options are `Ego`, `Jaz`, or `Enotnost`. Defaults to `Ego`.
- **tension**: Measure of internal stress on a scale from 0.0 to 1.0 (default `0.0`). Values above `0.7` may trigger a state transition.
- **emotion**: Emotional intensity on a scale from 0.0 to 1.0 (default `0.0`). Values above `0.5` may trigger a state transition.
