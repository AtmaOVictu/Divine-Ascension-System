# Divine-Ascension-System
UX HUB FOR INTERACTIVE COMMAND/

This project models philosophical agents capable of moving through the states
**Ego**, **Jaz** and **Enotnost**. It follows the principle:

> Ni nesreč, so le srečne naključnosti. (There are no accidents, only happy coincidences)

Agents interact, experience coincidences and transition between states based on
their emotional intensity and tension.
