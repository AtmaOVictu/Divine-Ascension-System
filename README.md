# Divine-Ascension-System

This repository contains a simple simulation of ontological agents that
transition between philosophical states based on **tension** and
**emotion**.  Agents discuss the nature of truth from the perspectives of
``Ego``, ``Jaz`` and ``Enotnost``.

## Running tests

All functionality is verified through unit tests.  To run them execute:

```bash
python -m unittest discover -s tests -v
```
