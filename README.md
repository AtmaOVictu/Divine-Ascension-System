# Divine-Ascension-System
UX HUB FOR INTERACTIVE COMMAND/

This project contains a minimal framework for simulating ontological agents.
Agents evolve through three philosophical states – **Ego**, **Jaz** and
**Enotnost** – as their emotion and tension levels change. Dialogues generated
by the system showcase how each state views absolute, relative and unified
truths.

## Running Tests

From the repository root execute:

```bash
python -m pytest -q
```
