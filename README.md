# Divine-Ascension-System

This project simulates philosophical debates between ontological agents. Each
agent can reside in one of three states:

* **Ego** – truth is absolute and independent of others.
* **Jaz** – truth is relative and shaped by relationships.
* **Enotnost** – all truths are unified and interconnected.

Agents transition between states when their tension exceeds ``0.7`` or their
emotion exceeds ``0.5``. The :mod:`divine_agents.dialogue` module provides a
utility for running dialogues and observing these transitions.
