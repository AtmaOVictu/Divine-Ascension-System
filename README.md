# Divine-Ascension-System

This project simulates philosophical agents that transition through
three ontological states: **Ego**, **Jaz**, and **Enotnost**. Agents
carry emotional intensity and tension which drive their transitions and
responses during debates.

## Modules

- `divine_agents.agent` – core Agent class managing state changes.
- `divine_agents.dialogue` – utilities for a simple dialogue.
- `divine_agents.debate` – multi-round debate logic.
