## Dynamic Agents

The package `divine_agents` contains a simple framework for modelling
philosophical agents. Each :class:`Agent` holds an ontological state
(``Ego``, ``Jaz`` or ``Enotnost``) and transitions between them occur
when either the agent's tension rises above ``0.7`` or the emotion
intensity exceeds ``0.5``.  Responses are influenced by the current
state and emotional mood and can be used to simulate dialogues or
debates.
