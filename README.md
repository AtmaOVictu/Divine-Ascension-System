# Divine-Ascension-System
This project provides simple ontological agents capable of transitioning
between philosophical states (``Ego`` → ``Jaz`` → ``Enotnost``).

Agents hold a lightweight DNA sequence that can mutate and they may
``reincarnate`` into new agents with slightly changed DNA.  A helper
function in ``dialogue.py`` demonstrates a short conversation and the
``tests`` folder contains unit tests verifying the transitions and
evolution utilities.
