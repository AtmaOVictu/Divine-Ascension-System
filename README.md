# Divine-Ascension-System

This repository implements a simple agent based framework for exploring
philosophical state transitions. Agents move between the ontological
states **Ego**, **Jaz** and **Enotnost** based on their emotional
intensity and internal tension. Dialogues showcase how emotions
influence their view on truth:

* **Ego** – truth is absolute.
* **Jaz** – truth is relative.
* **Enotnost** – all truths are unified.

## Ethics

Use this system responsibly. It is intended for philosophical and
educational exploration. Interactions should respect individual
perspectives and avoid causing harm.
