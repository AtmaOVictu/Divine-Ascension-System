# Divine-Ascension-System

To je eksperimentalni okvir za simulacijo filozofskih agentov. Agenti
prehajajo med stanji **Ego**, **Jaz** in **Enotnost** na podlagi čustev in
napetosti. Celotno ozadje ontoloških principov (DA in JA) ter primeri
uporabe so opisani v datoteki [ONTOLOGIJA.md](ONTOLOGIJA.md).
