# Divine-Ascension-System
UX HUB FOR INTERACTIVE COMMAND/

This repository contains a small demonstration of ontological agents that
transition between the states **Ego**, **Jaz**, and **Enotnost**. Agents change
their state when their tension exceeds `0.7` or their emotion exceeds `0.5`.

Unit tests are provided in `tests/` and can be run with:

```bash
PYTHONPATH=. pytest -q
```
