# Divine-Ascension-System

This project models agents that move through ontological states (**Ego**, **Jaz**, and **Enotnost**).
Agents hold emotional states which influence their tension levels and, consequently, their philosophical
perspective. When tension exceeds `0.7` or emotion intensity exceeds `0.5`, agents transition to the next
state. Dialogue functions simulate debates about absolute, relative, and unified truths with emotional
context.

Unit tests are provided in `tests/` to verify transitions and dialogue behaviour.
