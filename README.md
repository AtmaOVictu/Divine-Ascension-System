## Divine Agents

The package `divine_agents` contains simple components for simulating
ontological agents. Agents transition between the states **Ego**, **Jaz** and
**Enotnost** when their emotion or tension exceeds predefined thresholds.

### Modules

- `agent` – core agent class with transition logic
- `dialogue` – helper to create a short interaction
- `conversation` – extended debate showcasing emotional influence

Unit tests under `tests/` verify behaviour of transitions and dialogues.
