# Divine-Ascension-System
UX HUB FOR INTERACTIVE COMMAND/

This project simulates philosophical agents that transition between ontological states.

- **Agent**: basic entity with transitions from Ego to Jaz to Enotnost.
- **OppositeAgent**: variant that can switch to an opposite state when emotion or tension rises.
- Dialogues between agents illustrate differing views of truth.

Run tests with `python -m pytest -q`.
