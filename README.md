# Divine-Ascension-System

An interactive agent framework where ontological agents evolve through three states: **Ego**, **Jaz**, and **Enotnost**. Agents make moral decisions and engage in philosophical dialogue influenced by their emotions and tension levels.

## Installation

```bash
git clone <repo_url>
cd Divine-Ascension-System
pip install -r requirements.txt  # if a requirements file exists
```

## Running

Execute the example dialogue:

```bash
python -m divine_agents.dialogue
```

## Testing

Run the unit tests with:

```bash
python -m unittest discover -s tests
```

## Project Structure

- `divine_agents/agent.py` – agent implementation and state logic.
- `divine_agents/dialogue.py` – sample philosophical dialogue between agents.
- `tests/` – unit tests covering transitions and dialogue responses.
- `AGENTS.md` – in-depth explanation of agent design and behaviour.
