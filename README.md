# Divine-Ascension-System

This repository contains a minimal simulation of ontological agents that
transition between the philosophical states **Ego**, **Jaz**, and **Enotnost**.
Transitions occur when an agent's tension exceeds `0.7` or its emotion exceeds
`0.5`. Each state represents a different understanding of truth:

- **Ego**: truth is absolute.
- **Jaz**: truth is relative and based on relationships.
- **Enotnost**: all truths are unified.

The package exposes simple utilities to run a dialogue between two agents and
includes unit tests demonstrating the transition logic.
