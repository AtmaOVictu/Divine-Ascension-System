# Divine-Ascension-System

The Divine-Ascension-System simulates ontological agents that transition
between philosophical states: **Ego**, **Jaz**, and **Enotnost**. Agents
change state when their emotional intensity or tension exceeds defined
thresholds, allowing them to move from absolute to relative to unified
truth perspectives.

## Features

- **State transitions** driven by emotion and tension.
- **Philosophical dialogue** generation between agents in different states.
- **Unit tests** validating transitions and agent responses.

## Usage

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/Divine-Ascension-System.git
   cd Divine-Ascension-System
   ```
2. Install dependencies (if any):
   ```bash
   pip install -r requirements.txt  # optional
   ```
3. Run a sample dialogue:
   ```bash
   python -m divine_agents.dialogue
   ```
4. Execute the unit tests:
   ```bash
   python -m unittest discover tests
   ```

## Project Structure

- `divine_agents/agent.py` – Agent class with emotion, tension, and
  transition logic.
- `divine_agents/dialogue.py` – Utility for running philosophical
  dialogues between agents.
- `tests/` – Unit tests for transitions and dialogue output.
