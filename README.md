# Divine-Ascension-System

This project provides a simple framework for experimenting with ontological
agents. Agents move through philosophical phases (**Ego**, **Jaz** and
**Enotnost**) by accumulating **tension** or **emotion**.

## Git tagging

Branches can be annotated with git tags to mark the current philosophical
phase of development. Suggested tags:

* `EgoPhase` – features focused on absolute truths.
* `JazPhase` – work exploring relative viewpoints and relationships.
* `EnotnostPhase` – unified approaches and integrations.

Create a tag with `git tag <tag-name>` once a branch reaches a milestone.
