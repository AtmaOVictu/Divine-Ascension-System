# Divine-Ascension-System
UX HUB FOR INTERACTIVE COMMAND/

This project implements a set of ontological agents capable of moving
between the states **Ego**, **Jaz**, and **Enotnost** based on tension and
emotions. An `OmnipotentAgent` can supervise other agents, analyse their
behaviour, and enforce transitions when necessary.

Unit tests cover state transitions, dialogue responses, and supervisory
logic.
