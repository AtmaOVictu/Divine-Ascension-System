# Divine-Ascension-System

This project provides a minimal framework for experimenting with
ontological agents that transition between the philosophical states
**Ego**, **Jaz** and **Enotnost**. Agents store an emotional state and a level
of tension which drive these transitions. Dialogue utilities allow two
agents to debate the nature of truth.

## Running tests

Execute the following command from the project root:

```bash
python -m pytest -q
```
