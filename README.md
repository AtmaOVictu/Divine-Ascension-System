## Running Tests

Clone the repository and run the test suite with `pytest`:

```bash
git clone <repo>
cd Divine-Ascension-System
PYTHONPATH=. pytest
```

The `PYTHONPATH` ensures the `divine_agents` package is discoverable. If your
environment already resolves the package, running `pytest` alone is sufficient.
