# Divine-Ascension-System

This project simulates philosophical debates between dynamic agents. To run the
project locally:

1. Create a Python environment (Python 3.11 or later).
2. Install dependencies (currently there are none).
3. Run the unit tests:

```bash
PYTHONPATH=$(pwd) pytest -q
```

Agents transition between ontological states based on emotion and tension. See
`divine_agents/` for implementation details.
