# Divine-Ascension-System

This project provides a minimal framework for simulating ontological agents.
Agents progress through three philosophical states:

* **Ego** – truth is absolute and independent.
* **Jaz** – truth is relative, shaped by relationships.
* **Enotnost** – all truths are unified.

Agents transition between these states when their **tension** exceeds `0.7`
or their **emotion** intensity exceeds `0.5`. Dialogue functions demonstrate
how emotion influences the debate.

Run the unit tests with:

```bash
python -m pytest -q
```
