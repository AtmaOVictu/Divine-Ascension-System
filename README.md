# Divine-Ascension-System
This project demonstrates a simple ontological agent framework.

Agents transition between philosophical states (**Ego**, **Jaz**, and
**Enotnost**) based on their tension and emotion levels. They can engage in
dialogues reflecting absolute, relative and unified truths.

## Running Tests

Install the dependencies (only `unittest` from the standard library is
required) and run:

```bash
python -m unittest
```
