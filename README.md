# Divine-Ascension-System

A small framework for experimenting with ontological agents and simple
animations. It provides utilities to simulate philosophical dialogues
and a time-cycle loading animation.

## Modules

- **divine_agents.agent** – basic agent implementation capable of state
  transitions based on emotion and tension.
- **divine_agents.dialogue** – helper function for generating short
  dialogues between two agents.
- **divine_agents.time_cycle** – a logic-only simulator and optional
  Tkinter GUI for displaying a circular loading animation.

## Running Tests

```bash
python -m pytest -q
```
