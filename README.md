# Divine-Ascension-System

This repository contains a small framework for modelling ontological agents that interact through philosophical dialogue.

## Running Tests

The test suite can be executed with `pytest` or `python -m pytest` from the repository root. No installation step is required because the `tests` package adjusts `sys.path` so the `divine_agents` package is discoverable.

```bash
pip install pytest  # if not already installed
pytest
```
