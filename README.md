# Divine-Ascension-System

This project demonstrates a minimal agent-based ontology system. Agents
transition between three philosophical states based on their **tension** and
**emotions**:

- **Ego** – truth is absolute.
- **Jaz** – truth is relative.
- **Enotnost** – all truths are unified.

Dialogue functions allow agents to debate these concepts, and unit tests ensure
that transitions occur when emotion or tension thresholds are reached.
