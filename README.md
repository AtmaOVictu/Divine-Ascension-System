# Divine-Ascension-System

Small demonstrative framework for experimenting with ontological agents.
Each `Agent` can transition between the philosophical states **Ego**, **Jaz**
and **Enotnost** depending on its emotional intensity or tension.  A helper
function `philosophical_dialogue` illustrates a short conversation and will
update the agents' states accordingly.

Run the unit tests with:

```bash
python -m pytest -q
```

This repository is intentionally minimal and aims to showcase how agents can
evolve through dialogue.
