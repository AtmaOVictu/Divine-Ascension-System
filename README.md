# Divine-Ascension-System

This project contains a small agent-based simulation. Agents transition
between three ontological states (**Ego**, **Jaz**, **Enotnost**) according to
their emotional intensity and tension levels. Micro changes, called **NANO**
events, accumulate until a **MEGA** event boosts an agent into a new state.

Run the unit tests with:

```bash
python -m pytest -q
```
