# Divine-Ascension-System

This repository provides a small simulation of philosophical agents that
transition between three ontological states:

* **Ego** – truth is absolute.
* **Jaz** – truth is relative and shaped by relationships.
* **Enotnost** – all truths are unified.

Agents adapt their emotional state and tension which can trigger state
transitions.  A dialogue helper demonstrates how agents debate and evolve
during a conversation.

Unit tests cover state transitions, emotional responses and dialogue
generation.
