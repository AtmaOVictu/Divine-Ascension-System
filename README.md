# Divine-Ascension-System
This repository provides a minimal framework for experimenting with
ontological agents. Each agent can transition between the states **Ego**,
**Jaz** and **Enotnost** based on its emotional intensity and internal
tension.  Agents can also engage in short philosophical dialogues that
demonstrate how their state and emotions shape their view of truth.

Run the unit tests with `pytest` to verify the behaviour.
