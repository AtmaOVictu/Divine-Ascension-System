# Divine-Ascension-System
Ontological agent framework with philosophical dialogues.

## Features
- Agents transition between **Ego**, **Jaz**, and **Enotnost** states when
  emotion or tension thresholds are exceeded.
- Responses are influenced by the agent's current emotion type
  (e.g. fear, joy, anger).
- A simple dialogue simulator demonstrates state changes during
  conversation.

## Running tests

```bash
pytest
```
