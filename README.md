# Divine-Ascension-System

This project models a set of philosophical agents that move between three
ontological states: **Ego**, **Jaz** and **Enotnost**.  State transitions are
triggered when an agent's tension exceeds `0.7` or its emotion rises above
`0.5`.

## Installation

The system has no external dependencies.  Clone the repository and run the
tests to verify everything works:

```bash
pytest
```

## Usage

The `TESTI.ipynb` notebook demonstrates an interactive example where two agents
engage in a short dialogue and transition between states.  Open the notebook in
Jupyter and execute the cells to observe the behaviour.
