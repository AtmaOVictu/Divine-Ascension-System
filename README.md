# Divine-Ascension-System

This project demonstrates a simple ontological agent system. Agents transition
between the philosophical states **Ego**, **Jaz** and **Enotnost** based on their
tension and emotional intensity. Dialogues illustrate how emotions influence
their perspective on truth.

## Running Tests

The unit tests can be executed with:

```bash
pytest -q
```

They verify state transitions, emotional responses and the sample dialogue.
