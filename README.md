## Emotion and State Changes

Agents transition between ontological states based on their emotional
intensity and accumulated tension. When an agent's tension exceeds `0.7`
or its emotion is higher than `0.5`, the agent may move from **Ego** to
**Jaz**, or from **Jaz** to **Enotnost**. Dialogue interactions adjust these
values, so stronger emotional reactions increase the likelihood of a state
change.
