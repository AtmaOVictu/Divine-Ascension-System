# Divine-Ascension-System

This project contains a minimal agent-based framework for exploring
ontological transitions between **Ego**, **Jaz** and **Enotnost**.  Agents
change state based on their emotional intensity and tension and can hold
short philosophical dialogues reflecting their current phase.  A cyclical
"Enotnost" loading mechanic is provided to symbolise progress toward unity.

Run the unit tests with `pytest` to verify behaviour.
