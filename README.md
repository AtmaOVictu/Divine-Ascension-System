# Divine-Ascension-System

This project demonstrates a simple ontological agent framework where agents
transition between the states **Ego**, **Jaz** and **Enotnost**. Transitions are
triggered when the agent's tension exceeds `0.7` or its emotion exceeds `0.5`.

Agents can participate in short dialogues showcasing their philosophical
viewpoints influenced by their emotions.

Run the unit tests with:

```bash
PYTHONPATH=. pytest -q
```
