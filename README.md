# Divine-Ascension-System

This project contains a minimal framework for simulating ontological agents.
Agents transition through three philosophical states based on their emotion and
tension levels:

- **Ego** – truth is absolute.
- **Jaz** – truth is relative.
- **Enotnost** – all truths are unified.

The package provides utilities for generating dialogues between agents and for
computing mathematical interpolations of their emotional and tension
differences over time.

## Running Tests

Execute the unit tests with `pytest`:

```bash
pytest -q
```
