# Divine-Ascension-System

This repository contains a simple simulation of ontological agents. Each agent
can transition between the states **Ego**, **Jaz** and **Enotnost** when their
tension or emotion levels exceed defined thresholds. Emotions influence tension
using a logistic growth function and the current emotional label is reflected in
dialogue responses.

Unit tests cover state transitions, emotional responses and the philosophical
dialogue between two agents.
