# Divine-Ascension-System

This project explores philosophical state transitions for autonomous agents.

Agents move between **Ego**, **Jaz**, and **Enotnost** based on their emotional
intensity and internal tension. The code distinguishes personal ("zase")
behaviour handled by `Agent` and systemic ("zame") analysis handled by
`MetaAgent` and `FilozofskiPrehod`.

Unit tests verify that transitions occur once thresholds are exceeded and that
philosophical responses match each ontological state.
