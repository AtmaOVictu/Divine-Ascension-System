# Divine-Ascension-System
UX HUB FOR INTERACTIVE COMMAND/

This project demonstrates a minimal dynamic agent framework. Agents move
between ontological states (**Ego**, **Jaz**, **Enotnost**) when their tension or
emotion exceeds predefined thresholds. Dialogue generation showcases how
emotions such as fear or joy influence philosophical perspectives.

Run the unit tests with:

```
python -m pytest -q
```
