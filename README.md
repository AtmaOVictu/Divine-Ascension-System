# Divine-Ascension-System

This project implements a minimal agent-based framework exploring
ontological state transitions.  Agents move through the states **Ego**,
**Jaz** and **Enotnost** depending on their current tension and emotional
intensity.  The package provides simple utilities to simulate dialogues and
observe how the agents evolve.

## Running Tests

Unit tests are located in the `tests` directory and can be executed with:

```bash
python -m pytest -q
```

The tests verify state transitions and dialogue behaviour.
