## Dynamic Agents

The package includes agents that transition through ontological states
(Ego, Jaz, Enotnost). `DynamicAgent` supports activation via keys such as
`"wisdom"` in addition to tension and emotion thresholds.

Utility functions like `dynamic_debate` simulate dialogues where agents
transition states and respond based on their current philosophy.
