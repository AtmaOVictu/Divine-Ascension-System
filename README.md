# Divine-Ascension-System

This repository contains a small ontological agent framework used to simulate
philosophical debates. Agents can be in one of three states:

- **Ego** – truth is absolute and independent of others.
- **Jaz** – truth is relative and shaped by relationships.
- **Enotnost** – all truths are unified and interconnected.

Agents transition between these states when their internal tension or emotion
exceeds configured thresholds. The package provides simple utilities for agents
to interact and a test suite demonstrating the behaviour.
