# Divine-Ascension-System

Eksperimentalni okvir za raziskovanje ontoloških prehodov agentov med stanji **Ego**, **Jaz** in **Enotnost**. Sistem sledi filozofskim konceptom JA in DA ter omogoča simulacijo dialogov, kjer čustva in napetost vodijo spremembe stanja.

Več o ontoloških principih najdete v datoteki [ONTOLOGIJA.md](ONTOLOGIJA.md).
