# Divine-Ascension-System
UX HUB FOR INTERACTIVE COMMAND/

## Overview

This repository contains a simple framework for ontological agents and security-oriented helpers. Agents
transition between the states **Ego**, **Jaz**, and **Enotnost** based on tension and emotions. Additional
security agents demonstrate how data can be encrypted, anonymized, controlled, and deleted.

### Core modules
- `divine_agents.agent` – basic agent with state transitions.
- `divine_agents.dialogue` – produces a short philosophical dialogue between two agents.
- `divine_agents.security_agents` – provides helper agents for encryption, anonymization, access control,
  privacy preferences, and data deletion.

### Running tests
Use `python -m pytest -q` to run the unit tests that validate the agents' behavior.
