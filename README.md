# Divine-Ascension-System
Experimental framework for simulating ontological agents.

## Features

* Agents transition between **Ego**, **Jaz** and **Enotnost** based on
  emotion and tension thresholds.
* Philosophical dialogues showcase how agents reason about absolute,
  relative and unified truths.
* Utilities for generating OpenAI Batch API files and submitting jobs to
  process dialogues asynchronously.
