# Divine-Ascension-System
Ontological agents transition through philosophical states based on
emotion and tension.  Each agent can respond to questions about truth
according to its current state:

- **Ego** – truth is absolute.
- **Jaz** – truth is relative through relationships.
- **Enotnost** – all truths are unified.

Emotion names such as `fear` or `joy` influence tension and may trigger
state transitions when thresholds are exceeded.
