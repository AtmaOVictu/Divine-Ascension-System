# Divine-Ascension-System

This project demonstrates a simple ontological agent system. Agents transition
between three philosophical states based on their emotional intensity and
tension levels. The repository includes unit tests and an example dialogue to
illustrate these transitions.

## UI Approaches

You can extend the agents with a graphical interface using various Python
frameworks:

### Tkinter

- **When to use**: quick prototypes or lightweight desktop tools.
- **Why**: bundled with Python and easy to learn.
- **Example**: create sliders for tension and buttons to trigger state changes.

### PyQt

- **When to use**: feature-rich desktop applications requiring custom widgets.
- **Why**: provides advanced components and modern look and feel.
- **Example**: build dashboards with graphs showing emotional levels while
  agents debate.

### Dash

- **When to use**: web-based visualizations or remote interaction.
- **Why**: integrates with Plotly for live charts in the browser.
- **Example**: create a web page where users adjust agent emotions and see
  dialogue updates in real time.

Choose the approach that best fits your environment—Tkinter or PyQt for desktop
interfaces and Dash for browser-based applications.
