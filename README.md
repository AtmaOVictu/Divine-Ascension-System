# Divine-Ascension-System

This project explores philosophical state transitions between **Ego**, **Jaz**, and **Enotnost** using interactive agents. Agents respond to dialogue prompts according to their ontological phase and can evolve as their emotion and tension change.

## Features
- Ontological agents defined in `divine_agents`.
- Dialogue generation demonstrating absolute, relative, and unified truths.
- Unit tests validating transitions and responses.

## Running Tests
Execute the following command to run the unit tests:

```bash
python -m pytest -q
```
