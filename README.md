# Divine-Ascension-System

This package provides a simple framework for simulating ontological agents.
Agents can transition between philosophical states (Ego, Jaz, Enotnost) based
on their tension and emotional intensity. Emotions influence karma over time
and can be analysed through trend tracking utilities.

## Key Modules

* `agent` – core agent with transition logic
* `emotions` – expanded emotional model
* `karma` – accumulates karma according to emotions
* `dialogue` – demonstrates philosophical dialogue between agents
* `analytics` – utilities to track emotional trends

Run tests with:

```bash
PYTHONPATH=. pytest -q
```
