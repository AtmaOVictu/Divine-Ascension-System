# Divine-Ascension-System
This project provides simple ontological agents that transition between the
philosophical phases **Ego**, **Jaz** and **Enotnost**. Agents can engage in
dialogues about truth and evolve based on their tension and emotions.

## Dynamic Agents

The `DynamicAgent` class extends the base `Agent` with biological and social
phases controlled by logistic functions. A `MultiAgentSystem` container allows
multiple agents to update emotions and evolve together.

Run the unit tests with:

```bash
python -m pytest -q
```
