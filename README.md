# Divine-Ascension-System
UX HUB FOR INTERACTIVE COMMAND/

This package provides ontological agents capable of shifting between the
states **Ego**, **Jaz**, and **Enotnost**. Agents interact through philosophical
dialogues and evolve when their tension or emotion exceeds specific thresholds.

## Generator

A `Generator` can be used to amplify an agent's tension and trigger these
state transitions. When activated it supplies energy to an agent, allowing the
agent to progress through higher ontological phases.
