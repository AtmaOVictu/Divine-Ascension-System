# Divine-Ascension-System

Simple demonstration of an ontological agent system. Each agent can move
through three philosophical states:

* **Ego** – truth is absolute and individual.
* **Jaz** – truth is relative and shaped by relations.
* **Enotnost** – all truths are unified.

State transitions occur when an agent's tension exceeds `0.7` or its
emotional intensity rises above `0.5`. See ``divine_agents`` for the
implementation and ``tests`` for usage examples.
