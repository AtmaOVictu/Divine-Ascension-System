# Divine-Ascension-System
This repository contains a simple simulation of ontological agents that
transition between states (``Ego``, ``Jaz`` and ``Enotnost``) based on their
emotion and tension levels.  Agents engage in short philosophical dialogues
that illustrate absolute, relative and unified perspectives on truth.

Unit tests ensure that state transitions occur once the defined thresholds are
met and that the dialogue reflects both the ontological and emotional state of
each agent.
