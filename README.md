# Divine-Ascension-System

This project demonstrates a simple ontological framework where agents
transition between philosophical states based on emotion and tension. It
includes utilities for simulating dialogues and unit tests verifying the
behaviour of the agents.

## Running Tests

Create a virtual environment and install the requirements (only `pytest` is
needed for running the tests)::

    python -m venv venv
    source venv/bin/activate
    pip install pytest

Execute the test suite::

    python -m pytest -q
