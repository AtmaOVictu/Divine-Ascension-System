# Divine-Ascension-System

Simple ontological framework for simulating agent interactions.

Features:

- Agents transition between **Ego**, **Jaz** and **Enotnost** when
  tension (>0.7) or emotion (>0.5) thresholds are exceeded.
- Fame and algorithmic participation influence decision processes.
- Utility functions allow basic philosophical dialogues and fame-based
  influence calculations.
- Unit tests ensure transitions, responses and fame calculations behave
  correctly.
