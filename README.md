# Divine-Ascension-System

Ta repozitorij prikazuje preprost agentski sistem, kjer agenti prehajajo med
ontološkimi stanji **Ego**, **Jaz** in **Enotnost**. Na prehode vplivata
čustvena intenziteta in stopnja napetosti. Datoteke v mapi `divine_agents`
vsebujejo implementacijo agentov in dialoga med njimi.

## Zagon testov

Vsi testi so napisani v slovenščini in angleščini. Za izvajanje uporabite:

```bash
pytest -q
```

Testi preverijo pravilnost prehodov in filozofskih odgovorov agentov.
