# Divine-Ascension-System

This project provides a minimal agent-based framework used for exploring
ontological state transitions. Agents move between the philosophical
states ``Ego``, ``Jaz`` and ``Enotnost`` depending on their emotional
levels and tension.  A small dialogue engine demonstrates how agents can
interact and evolve during a conversation.

## Running Tests

Install the required dependencies (only `pytest` is needed) and run:

```bash
python -m pytest -q
```
