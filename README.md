# Divine-Ascension-System

Simple simulation of ontological agents that transition between philosophical
states. Each agent contains a unique *nomen* value describing its current state
and emotional context. Dialogue between agents demonstrates shifts from **Ego**
to **Jaz** and eventually **Enotnost** when tension or emotion thresholds are
exceeded.

## Tests

Run unit tests with:

```bash
python -m pytest -q
```
