# Divine-Ascension-System

A simple framework for simulating ontological agents.

## Features

- **Agent** class supporting emotional and tension-based state transitions.
- **Philosophical dialogue** utilities to generate conversations.
- **Tkinter interface** for real-time experimentation.
- Unit tests covering basic behaviour.

## Running the interface

```bash
python -m divine_agents.interface
```

## Running tests

```bash
python -m pytest -q
```
