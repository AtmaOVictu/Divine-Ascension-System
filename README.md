# Divine-Ascension-System
UX HUB FOR INTERACTIVE COMMAND/

## Codex Elements

The system revolves around ontological agents that evolve through three
philosophical states:

- **Ego** – truth is viewed as absolute and independent.
- **Jaz** – truth becomes relative, shaped through relationships.
- **Enotnost** – all truths unify and become interconnected.

Agents carry emotional states which raise their tension. When tension is above
`0.7` or emotion intensity above `0.5`, they transition from **Ego** to **Jaz** or
from **Jaz** to **Enotnost**. Dialogues between agents highlight these shifts and
illustrate how emotions influence philosophical perspectives.
