# Divine-Ascension-System

This project simulates philosophical agents that evolve through the states **Ego**,
**Jaz**, and **Enotnost**. Agents adjust their emotional intensity and tension, and
transition when either surpasses the defined thresholds. The `philosophical_dialogue`
function demonstrates how agents debate absolute, relative, and unified truths while
their emotions influence the conversation.

Run the unit tests with:

```bash
python -m unittest
```
