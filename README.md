# Divine-Ascension-System

This project provides a lightweight framework for simulating ontological agents.
Agents transition through three philosophical states depending on their
emotions and tension:

- **Ego** – truth is absolute and independent of others.
- **Jaz** – truth is relative and shaped by relationships.
- **Enotnost** – all truths are unified and interconnected.

Utilities are included for generating dialogues between agents and for
observing how emotional intensity drives state transitions.

## Running Tests

To run the unit tests execute:

```bash
pytest -q
```
