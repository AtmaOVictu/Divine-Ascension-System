# Divine-Ascension-System

This project contains a small framework for simulating philosophical agents.

Agents transition through three ontological states:

* **Ego** – truth is absolute.
* **Jaz** – truth is relative.
* **Enotnost** – all truths are unified.

Transitions are triggered when an agent's tension exceeds `0.7` or when its
emotional intensity is above `0.5`. Dialogues between agents modify these
values and may cause state changes.

Run the unit tests with:

```bash
python -m pytest -q
```
