# Divine-Ascension-System

This repository contains simple ontological agents that can transition between philosophical states and participate in dialogues.

## Running Tests

```bash
pytest -q
```

## Interactive Demo

A small REPL example is provided via `demo_repl.py`. Run it with Python to interact with an agent:

```bash
python demo_repl.py
```

Type `quit` or `exit` to end the session.
