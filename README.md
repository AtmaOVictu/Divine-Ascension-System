# Divine-Ascension-System

A small framework for experimenting with ontological agents. Agents
transition between philosophical states (*Ego*, *Jaz*, *Enotnost*) when
their emotion or tension exceeds defined thresholds.

## Features

- **Agent** class with emotion-driven state transitions.
- **philosophical_dialogue** helper to demonstrate conversations.
- **OuroborosCycle** utility for looping through the three states.

Run tests with `python -m unittest`.
