# Divine-Ascension-System

This project simulates ontological agents that evolve through the states
**Ego**, **Jaz**, and **Enotnost**. Agents transition when their tension or
emotion exceeds certain thresholds and respond with philosophical answers
based on their state.

## Omnipotent Agent

An `OmnipotentAgent` can supervise multiple agents, analyse their behaviour,
and force state transitions when high tension or negative emotions are
detected. See `divine_agents/omnipotent_agent.py` for details.
