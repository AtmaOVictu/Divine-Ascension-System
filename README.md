# Divine-Ascension-System

UX HUB FOR INTERACTIVE COMMAND/

This project provides simple ontological agents capable of transitioning between
philosophical states (*Ego*, *Jaz*, *Enotnost*). It also includes a small GUI
utility demonstrating how a transition window can be shown using `tkinter`.

## Usage

```bash
# Run a philosophical dialogue in Python
python -m divine_agents.dialogue

# Launch the transition window GUI
python -m divine_agents.ui
```
