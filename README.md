# Divine-Ascension-System
This project demonstrates a small agent framework used for experimenting with
ontological state transitions and philosophical dialogues.  Agents start in the
``Ego`` state and can progress through ``Jaz`` to ``Enotnost`` when their
tension or emotional intensity exceeds defined thresholds.

Each agent can respond to questions about truth. Their replies reflect their
current ontological state and emotional charge.  Dialogues between two agents
show how these states evolve over time.

Run the unit tests with::

    python -m pytest -q
