# Divine-Ascension-System

This project provides a minimal framework for experimenting with ontological
agents that move through the phases **Ego → Jaz → Enotnost**.  Agents hold a
level of emotional intensity and tension; when either metric crosses the
configured thresholds they advance to the next philosophical state.

The package exposes simple classes for creating agents and running dialogues
between them.  Unit tests demonstrate that transitions, responses and basic
state persistence work as expected.
