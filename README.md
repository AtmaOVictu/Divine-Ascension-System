# Divine-Ascension-System

This repository implements a simple agent based framework for exploring
philosophical state transitions. Agents move between the ontological
states **Ego**, **Jaz** and **Enotnost** based on their emotional intensity
and internal tension. Dialogues showcase how emotions influence their
view on truth:

* **Ego** – truth is absolute.
* **Jaz** – truth is relative.
* **Enotnost** – all truths are unified.

Running the unit tests requires pytest:

```bash
PYTHONPATH=. pytest -q
```

## Ethics

Use this system responsibly. It models emotional agents engaging in
philosophical debates. Results are for educational and research purposes
only.
