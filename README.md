# Divine-Ascension-System

This repository implements a simple agent based framework used to explore
ontological states. Agents transition between the states **Ego**, **Jaz** and
**Enotnost** based on their emotional intensity and tension levels. Emotions can
increase or decrease tension and therefore influence the transition to a higher
state.

## Running tests

Unit tests are stored in the `tests/` directory and can be executed with

```bash
pytest -q
```
