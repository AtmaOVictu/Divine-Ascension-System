# Divine-Ascension-System
UX HUB FOR INTERACTIVE COMMAND/

This project simulates interactions between ontological agents that can move
through the states **Ego**, **Jaz** and **Enotnost**.  Agents hold an emotional
state that influences their tension and philosophical responses.  When the
tension exceeds `0.7` or the emotion intensity exceeds `0.5`, an agent
transitions to the next state.

Unit tests (`pytest`) verify transitions, emotional responses and the dialogue
flow between agents.
