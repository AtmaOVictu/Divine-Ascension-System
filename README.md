# Divine-Ascension-System

This project provides a minimal agent-based framework exploring
philosophical transitions between the ontological states **Ego**, **Jaz** and
**Enotnost**.  Agents react to their emotional intensity and tension, allowing
them to progress through these phases while exchanging short dialogues about
truth.  Unit tests demonstrate state transitions, emotional influences and the
"ionization" of words (shifting characters by one).

To run the tests:

```bash
PYTHONPATH=. pytest -q
```
