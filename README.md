# Divine-Ascension-System

This project contains a simple framework for simulating ontological agents.
Agents transition between the states **Ego**, **Jaz**, and **Enotnost** based on
their emotional intensity and tension. Dialogue helpers allow agents to debate
concepts of truth while their emotions influence state changes.

Running the unit tests requires setting the `PYTHONPATH` environment variable so
the package can be resolved:

```bash
PYTHONPATH=. pytest -q
```
