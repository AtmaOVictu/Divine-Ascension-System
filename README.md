# Divine-Ascension-System

This project provides simple agent classes and utilities for simulating
philosophical state transitions. Agents shift between **Ego**, **Jaz** and
**Enotnost** depending on tension and emotion.

## Modules

- `divine_agents.agent` contains the `Agent` class with transition logic.
- `divine_agents.dialogue` provides a helper for short dialogues between agents.
- `divine_agents.tension` offers functions to analyze tension and return
  key words for its phases.

## Running Tests

Execute `pytest` in the repository root to run the unit tests.
