# Divine-Ascension-System

This project provides a minimal agent framework that explores philosophical concepts through dialogue. Agents transition between ontological states (Ego, Jaz, Enotnost) depending on their emotion and tension levels.

## Running the example dialogue

1. Ensure you have **Python 3.11** or later installed.
2. From the repository root, run:

```bash
python run_dialogue.py
```

The script will create two agents and print their conversation along with any state transitions that occur.

## Running the tests

The unit tests verify correct state transitions and responses. Execute them with:

```bash
python -m pytest -q
```

All tests should pass and demonstrate the expected behaviour of the agents.
