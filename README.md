# Divine-Ascension-System

This project demonstrates a simple agent-based framework for exploring ontological
states. Agents transition between **Ego**, **Jaz**, and **Enotnost** depending on
tension and emotional intensity. They can engage in short dialogues or full
philosophical debates where their emotions influence these transitions.

## Running Tests

Use `pytest` or the Python `unittest` module to run the included tests:

```bash
python -m pytest -q
```

or

```bash
python -m unittest
```
