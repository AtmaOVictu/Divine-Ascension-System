# Divine-Ascension-System

This project simulates ontological agents that evolve through philosophical
states. Agents transition from **Ego** to **Jaz** and eventually to
**Enotnost** when their internal tension or emotional intensity exceeds
configured thresholds. Each state reflects a different view on truth:

* **Ego** – truth is absolute.
* **Jaz** – truth is relative and formed through relationships.
* **Enotnost** – all truths are unified.

The package includes simple dialogue utilities and unit tests demonstrating the
transitions and responses influenced by emotions such as fear, anger and joy.
