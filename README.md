# Divine-Ascension-System

This repository contains a minimal agent system exploring ontological states.
Agents transition between **Ego**, **Jaz**, and **Enotnost** depending on their
emotion and tension levels. The dialogue module demonstrates how emotions drive
these transitions.

## Running Tests

Unit tests ensure that state transitions and philosophical responses behave as
expected. Execute them with:

```bash
python -m pytest -q
```
